# Optic Canvas Support

Optic Canvas is a local image toolkit for Mac, iPhone and iPad.

- [Privacy Policy](PRIVACY.md)
- [Terms of Use — Apple Standard EULA](https://www.apple.com/legal/internet-services/itunes/dev/stdeula/)
- [Report a problem](https://github.com/sushanth21042004/optic-canvas-support/issues)

Monthly and yearly Pro plans renew automatically until cancelled. Lifetime Pro is a one-time purchase. All plans unlock the same Pro features. Prices are displayed in the app using your App Store storefront.

Use Settings → Restore Purchases with the Apple Account used for the purchase. To change or cancel a subscription, use Settings → Manage Subscription or https://apps.apple.com/account/subscriptions. Buying Lifetime does not automatically cancel an existing subscription. Deleting the app does not cancel it either.

For support, include the app version, device/OS version, tool and steps to reproduce. Public GitHub issues must not contain private images, payment details or sensitive information.
